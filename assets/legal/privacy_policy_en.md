# Privacy Policy

**Last updated:** 2026-08-20

## Controller
TRAUM App · Contact: via GitHub — github.com/Lupus-atque-Corvus/Traum-APP (Issues)

## What data we process
TRAUM stores data exclusively locally on your device:
- Profile data (name, age, weight, height)
- Health and fitness data (training, sleep, steps, heart rate)
- Nutrition data (meals, calories, water)
- Financial data (budget, transactions)
- Medication and supplement data (including intake log)
- Cycle data (only if enabled)
- Photos and videos (diary entries, map marker photos, receipt photos)
- Location data (map marker coordinates, photo GPS metadata if present, location used for
  weather data)
- Notes
- Calendar data (only if calendar sync is enabled)

## Where data is stored
**All data remains exclusively on your device.** There is no server of our own,
no cloud, no automatic transfer to third parties.

## External services
These services are only contacted from the corresponding feature, and only while it's
actively being used:
- **OpenMeteo API** (api.open-meteo.com): For weather data, coordinates
  (latitude/longitude) are transmitted. No other personal data.
- **Map tiles** (OpenStreetMap, CARTO, Esri/ArcGIS): Viewing the Graffiti Map transmits the
  visible map viewport to these providers to load the map imagery.
- **Geocoding** (your device's built-in Android/iOS service): Converting coordinates into an
  address (e.g. when creating a map marker) sends coordinates to your device manufacturer's
  geocoding service.
- **OpenFoodFacts API** (world.openfoodfacts.org): Scanning a barcode or searching for a
  product in Nutrition transmits the barcode or search term.
- **USDA FoodData Central API** (api.nal.usda.gov): Only if you've entered your own API key
  in Settings, nutrition searches transmit the search term.
- **Health Connect / Apple Health:** Health data is retrieved from your device
  manufacturer's platform. Their privacy policies apply.
- **GitHub:** App update checks query the GitHub API (no user data transmitted). The Feedback
  button opens a pre-filled GitHub issue form in your browser — you see and control the
  content before it's submitted.

## Device-to-device backup transfer (LAN)
You can send a backup directly to another device on the same WiFi (Settings → "Send to
another device" / "Receive from another device"). This transfer runs entirely within your
local network, end-to-end encrypted, without any server or cloud service involved. It only
starts when you actively trigger it, and the receiving device must additionally confirm the
transfer twice before any data is applied.

## Your rights (GDPR)
- **Access:** All data is visible in the app
- **Correction:** All fields are editable
- **Deletion:** Settings → Delete all data
- **Portability:** Settings → Export data (JSON/CSV), or transfer it directly to another
  device (see above)
- **Withdrawal:** Settings → Delete all data lets you withdraw consent at any time — this
  permanently deletes all stored data

## Special categories of data
Health data is specially protected under GDPR Art. 9.
You expressly consent to their processing (Art. 9 para. 2 lit. a).
Processing takes place exclusively locally on your device.

## Complaints
Competent supervisory authority: the data protection authority of your country/region.
